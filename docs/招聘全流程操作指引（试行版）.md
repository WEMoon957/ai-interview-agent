# 招聘全流程操作指引（试行版）

> **适用系统**：AI 招聘系统（interview-agent）
> **试行对象**：HR + 门店店长
> **版本**：v1.0 试行版　｜　整理日期：2026-10-14

---

## 一、这份文档怎么用

试行期内，从「发岗位、看简历、约面试」到「定人选、留记录」，全部在这套系统里跑通。本文按**你实际操作的时间顺序**写，每个环节都告诉你三件事：

- **谁来做** —— HR 还是店长
- **在哪里做** —— 后台哪个页面
- **做完会怎样** —— 系统自动做什么、飞书会推给你什么

遇到文档没覆盖的问题，请在《飞书试用反馈收集表》里记一条（见第十一节）。

## 二、全流程一图看懂

```
准备：建岗位 → 配面试模板 → 写公司介绍
  │
  ▼
① 简历初筛（HR 上传简历文件夹，AI 逐份打分排序）
  │   达标者自动生成 AI 面试链接，推卡片 + 建飞书待办
  ▼
② AI 面试（候选人点链接自助作答，约 15~30 分钟）
  │   综合分达标自动推 HR 飞书
  ▼
③ 线下复试（HR / 店长约面 → 现场面试 → 录入分数与结论）
  │
  ▼
④ 汇总落库（HR 点一下按钮，聚合三段分数并写快照）
  │   自动推「复核 + 办 offer / 入职」提醒
  ▼
HR 复核 → 发 offer → 办入职
```

| 阶段 | 谁来做 | 系统做什么 |
| --- | --- | --- |
| 准备 | HR | 建岗位、配面试模板、维护公司介绍 |
| ① 简历初筛 | HR | 上传岗位文件夹，AI 按 JD 逐份打分并排序 |
| ② AI 面试 | 候选人 | 自助作答，AI 自动追问并逐题评分 |
| ③ 线下复试 | HR / 店长 | 约面、现场面试、录入分数与结论 |
| ④ 汇总落库 | HR | 聚合三阶段分数，提醒办 offer 与入职 |

> **一句话概括**：HR 上传一个岗位文件夹，系统自动初筛排序并把面试链接推到飞书；候选人自助完成 AI 面试；HR / 店长线下复试打分；最后一键汇总落库并提醒办 offer 与入职。

## 三、开始前的一次性准备

这三件事做一次就够，之后一直复用。

### 3.1 建岗位（在「岗位管理」页）

1. 点「新建岗位」，填**岗位名称**（如：店员、后厨、店长）、JD 描述、技能要求
2. 保存后岗位出现在列表里
3. 岗位可切换**免初筛**开关：开启后，上传简历跳过 AI 打分，直接发 AI 面试链接（详见第五节）

### 3.2 配面试模板（在「面试模板」页）

模板决定「AI 考什么、怎么评分」：

1. 点「新建模板」，选择所属岗位
2. **预设问题**：建议 3~5 题。每题可选题型：
   - **主观题**：候选人自由作答，AI 评分
   - **选择题**：候选人单选，系统按预设正确答案确定性判分，不消耗 AI
3. **评分维度**：设置维度和权重，**权重之和必须等于 1**（系统默认已给四个维度）
4. **追问上限**：每题最多追问几次（默认 2，填 0 表示不追问）

> **建议**：文化匹配类问题（如「我们正处于快速开店期、节假日最忙，你能接受吗？」）很适合放一道在题集里，配合第三节 3.3 的公司介绍一起用。

### 3.3 写公司介绍（在「公司文化」页）★ 本次新增

这是本次试行新加的环节，**写一次，之后所有面试自动带上**。

1. 进入「公司文化」页，写清四件事：
   - **公司是谁**：品牌、主营业务、门店规模
   - **现状如何**：发展节奏、旺季时段、近期重点
   - **团队氛围**：相处方式、管理风格
   - **用工特点**：班次、节假日安排、晋升路径、福利
2. 点「保存」，页面下方会实时预览**候选人打开链接时看到的开场白**

**三条要记住的规则**：

| 规则 | 说明 |
| --- | --- |
| 快照隔离 | 发起面试时把当时的介绍**快照**进这场面试。之后再改介绍，**只影响之后发起的面试**，已发出的面试仍用旧内容 |
| 只展示前 300 字 | 开场白只带前 300 字，超出部分仅后台留存（页面有字数提示） |
| 留空不影响 | 没写介绍时，开场白走通用文案，不影响任何流程 |

## 四、四个阶段的逐步操作

### ① 简历初筛（HR）

在「简历初筛」页：

1. 上传**岗位文件夹**（一个文件夹 = 一个岗位的多份简历），选择对应岗位
2. 系统逐份解析简历（支持 PDF / Word / 文本），按 JD 四维打分：技能匹配、经验相关、稳定性、素质与态度
3. 上传完成后得到一张**降序榜单**，展示每人的总分、亮点、风险

**系统自动做的事**（达到门槛者）：

- 生成 AI 面试链接
- 推一张卡片到 HR 飞书（岗位、本次统计、推荐名单含链接）
- 建一条飞书待办（含候选人、分数、面试链接、截止时间）

也可以点「推送榜单给 HR」手动补推。

### ② AI 面试（候选人自助，HR 无需在场）

候选人打开链接后：

1. 先阅读并同意《安全知情协议》
2. 看到**开场白**（含公司介绍）
3. 逐题作答，回答不够深入时 AI 会**自动追问**
4. 答完显示「面试已完成」

**系统自动做的事**：逐题评分 → 维度加权 → 生成百分制报告（含录用建议与维度雷达图）；**综合分达到阈值时自动推 HR 飞书**。

HR 侧可在「面试会话」页查看所有人的链接与状态，在「评分报告」页看详情。候选人中途退出不会丢进度，重新打开即可继续。

### ③ 线下复试（HR / 店长）

在「线下复试」页，顶部是**「待 HR 处理」列表**（初筛达标 + AI 面试完成的人会进来）：

1. 点「约面」，填时间、地点、面试官、面试官角色（HR / 店长）
2. 面试结束后录入：**百分制总分 + 维度明细 + 评语 + 结论**（通过 / 待定 / 淘汰）
3. 若候选人临时未到，可标记状态，避免悬空

**到店直招**（候选人直接到门店，没有简历）见第五节。

### ④ 汇总落库（HR 一键完成）

在「数据汇总」页：

1. 选岗位，系统**实时聚合**三阶段分数：初筛分、AI 面试分、线下复试分
2. 点「落库」，把汇总结果写成快照（可导出 CSV）
3. 系统自动推「复核 + 办 offer / 入职」提醒卡片与待办

**最终加权分** = 初筛 × 0.2 + AI 面试 × 0.4 + 线下 × 0.4。

> **缺环节不惩罚**：如果某人不走初筛或不走 AI 面试，系统会对**已有环节重新归一化**，不会因为缺环节而拉低分数。

## 五、两个特殊分支

### 5.1 免初筛岗位

岗位标记「免初筛」后：上传简历**不做 AI 打分**，直接为每位候选人生成 AI 面试链接；汇总时不计初筛分，权重自动重新归一化。

**适合场景**：简历量不大、想快速铺开面试时。

### 5.2 到店直招（现场面试）

候选人不带简历、直接到门店找店长：

| 步骤 | 操作 |
| --- | --- |
| 1 | 「线下复试」页 → 点「到店直招」 |
| 2 | 一次建档：岗位 + 姓名 + 手机号 + **来源渠道** |
| 3 | 现场面试，可上传**整场面试录音**（mp3 / m4a / mp4 / wav，单文件 ≤ 50MB，支持回放与下载） |
| 4 | 面试后直接人工打分（口径同线下复试） |

**注意**：

- 同一候选人**同一岗位**重复建档会被拒绝（避免重复提交）
- 同「姓名 + 手机号」会复用同一份候选人档案
- 汇总里会标明「来源 = 到店直招」

> 录音目前**只存档、不自动转文字**，打分由店长人工录入；自动转写是后续阶段的能力。

## 六、分数是怎么算出来的

| 分数 | 算法 |
| --- | --- |
| 初筛分 | 按 JD 四维打分（技能匹配 / 经验相关 / 稳定性 / 素质与态度），权重归一化后重算百分制 |
| AI 面试分 | 逐题按模板 rubric 打分 → 各维度均分 × 权重 → 百分制 |
| 线下复试分 | HR / 店长人工录入（可带维度明细） |
| 最终加权分 | 初筛 × 0.2 + AI 面试 × 0.4 + 线下 × 0.4（缺环节时重新归一化） |

**档位**：≥ 80 强烈推荐　｜　≥ 65 推荐　｜　≥ 50 待定　｜　\< 50 不推荐

## 七、飞书会推什么给你

| # | 触发时机 | 形态 | 内容要点 |
| --- | --- | --- | --- |
| ① | 简历初筛完成 | 卡片 | 岗位、本次统计、推荐名单（含 AI 面试链接） |
| ② | 简历初筛完成 | 待办 | 候选人、分数、面试链接、截止时间 |
| ③ | AI 面试完成且达标 | 消息 | 候选人、综合分、录用建议、维度得分 |
| ④ | 汇总落库完成 | 卡片 | 「建议发放 offer」与「建议复核后决定」两组 |
| ⑤ | 汇总落库完成 | 待办 | 待复核人数、两组候选人与三段分数 |

- 收件人按**部门实时解析在职成员**，新人自动纳入、离职自动过滤，无需手工维护名单
- 推送失败**不影响业务落库**，可到对应页面手动补推

## 九、候选人那边会看到什么

1. 打开链接 → 阅读并同意《安全知情协议》
2. 看到**开场白**：问候语 + 公司介绍 + 答题说明
3. 逐题作答，页面显示进度（第 X / Y 题）
4. 回答较浅时出现追问提示
5. 全部答完显示「面试已完成」

**告知候选人的话术建议**：「这是一场 AI 面试，大约 15~30 分钟。请尽量结合真实经历具体作答，回答越具体，AI 的判断越准。中途可以退出，重新打开链接会接着上次继续。」

## 十、试行期注意与已知限制

| 事项 | 现状 |
| --- | --- |
| 飞书待办 | 应用权限待开通，**待办可能创建失败**（卡片不受影响） |
| 面试录音 | 仅存档与回放，**不自动转文字**，打分由店长录入 |
| 简历量大 | 初筛是逐份调用 AI，上传大文件夹会较慢，建议分批 |
| 链接可访问性 | 候选人链接基于部署域名生成，若 HR 或候选人打不开，请联系管理员确认公网地址 |
| 数据权限 | 后台暂无登录与角色区分，试行期请注意访问范围 |

## 十一、遇到问题怎么反馈

请在《**飞书试用反馈收集表**》（多维表格）里记一条，字段按提示填：

1. **提出人 + 角色**（HR / 店长 / 候选人）
2. **所属模块**（哪个页面出的问题）
3. **问题描述**（做了什么操作、期望什么、实际发生了什么）
4. **我的建议**（你希望怎么改）
5. **严重程度**（阻塞 / 高 / 中 / 低）

有截图更佳。每周汇总一次，按「阻塞 → 高 → 中 → 低」的顺序处理，处理结果会回填在表里。
