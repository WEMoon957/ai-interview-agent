# 笨二娘隆江猪脚饭 · AI 面试系统（测试版）使用说明

> 版本：v0.1 测试版 ｜ 更新时间：2026-10-10
> 适用对象：面试官、HR、参与测试的候选人

---

## 一、系统简介

本系统是一套 **AI 智能面试** 工具，用于门店员工/岗位招聘面试：

- **AI 自动出题 + 追问**：根据岗位 JD 和候选人简历，逐题提问，回答不够深入时自动追问
- **自动评分**：按预设维度（技术深度、项目经验、沟通表达、岗位匹配等）逐题打分
- **生成面试报告**：综合分（百分制）+ 录用建议（强烈推荐/推荐/待定/不推荐）+ 维度雷达图

系统分两个端：

| 端 | 使用者 | 说明 |
| --- | --- | --- |
| 管理员后台 | 面试官 / HR | 创建岗位、配置面试模板、发起面试、查看评分报告 |
| 面试页 | 候选人 | 通过链接进入，逐题作答 |

## 三、管理员后台操作流程

进入后台后，左侧有 5 个菜单：**概览 / 岗位管理 / 面试模板 / 面试会话 / 评分报告**。

完整的使用流程是：

```
① 岗位管理（建岗位） → ② 面试模板（配问题+评分维度） → ③ 面试会话（发起面试、生成链接） → ④ 候选人面试 → ⑤ 评分报告（查看结果）
```

### ① 岗位管理

1. 点「新建岗位」，填写岗位名称（如：店员、后厨、店长）、JD 描述、技能要求
2. 保存后岗位出现在列表
3. 每个岗位可点「删除」（会同时删除该岗位下的所有模板和面试数据，请谨慎）

### ② 面试模板

为某个岗位配置「考什么、怎么评分」：

1. 点「新建模板」，选择岗位
2. **预设问题**：添加面试问题（建议 3~5 题），例如「你之前有餐饮行业经验吗？」
3. **评分维度**：设置评分项和权重，默认已配好 4 项（技术深度/项目经验/沟通表达/岗位匹配），权重之和必须等于 1
4. **追问上限**：每题最多追问几次（默认 2）
5. 保存后可点「删除」删除模板

### ③ 面试会话（发起面试）

1. 点「创建面试」
2. 选择面试模板
3. 填写候选人姓名、邮箱（选填）、电话（选填）
4. 上传候选人简历（支持 PDF / Word / 文本，可选）
5. 点「创建」，系统生成一个**面试码**（答题链接）

创建成功后：
- 点「打开面试页」直接进入面试
- 或点「复制链接」把面试链接发给候选人

### ④ 评分报告

候选人完成面试后，在「评分报告」页：

1. 顶部下拉框选择对应候选人
2. 查看：
   - **综合分**（百分制）和 **录用建议**（强烈推荐/推荐/待定/不推荐）
   - **维度雷达图**（各维度得分可视化）
   - **维度得分表**（每个维度的得分和权重）
   - **逐题评分明细**（每题的打分 + 评语 + 追问）

## 四、候选人面试流程

候选人拿到面试链接后：

1. 打开链接，看到**欢迎语（开场白）**
2. 页面显示**当前问题**和答题进度（第 X / Y 题）
3. 在文本框输入回答，点「提交回答」
4. 如果回答不够深入，AI 会**追问**（页面有黄色提示「面试官针对你的回答进行了追问」）
5. 回答完所有问题后，页面显示「面试已完成」

**候选人注意事项：**
- 面试链接**只能使用一次**，中断后可刷新页面继续（系统会恢复进度）
- 手机、电脑均可面试，手机端已做适配
- 回答请尽量具体、结合真实经历，AI 会据此打分

## 五、常见问题（FAQ）

**Q1：公网地址打不开？**
A：测试版使用临时域名，若报「Origin DNS error」说明穿透服务中断，请联系管理员重启，重启后会生成新域名。

**Q2：面试码（token）是什么？**
A：创建面试会话时系统自动生成的一串字符，拼在 `/i/` 后面就是候选人的答题链接。

**Q3：候选人中途退出，面试会丢吗？**
A：不会。系统会保存面试进度，候选人重新打开链接可继续作答。

**Q4：删除岗位/模板/会话会怎样？**
A：会**级联删除**其下的所有关联数据（会话、评分、报告、简历），删除前会有二次确认，删除后不可恢复。

**Q5：评分是怎么算的？**
A：每题按预设维度打分，最后取各维度所有题的平均分 × 权重，加权汇总成百分制综合分，再按阈值（90/75/60）给出录用建议。
