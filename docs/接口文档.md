# AI 面试系统 · API 接口文档

> 版本：v0.1 测试版 ｜ 更新时间：2026-10-10
> 本文档供**外部系统接入**使用，涵盖系统全部 HTTP 接口。

---

## 一、基础信息

### 1.1 Base URL

| 环境 | 地址 |
| --- | --- |
| 本地开发 | `http://localhost:8000` |
| 公网（测试） | `https://net-dare-watching-transcription.trycloudflare.com`（经前端代理，实际后端为 8000 端口） |

> ⚠️ 公网地址为临时域名，会随内网穿透重启而变化；生产接入请使用正式域名。

### 1.2 鉴权

当前测试版**接口未加鉴权**，可直接调用。生产环境将增加 API Key 鉴权，届时需在请求头携带 `Authorization`。

### 1.3 统一响应格式

所有接口返回统一 JSON 结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 0 表示成功，非 0 表示失败 |
| message | string | 提示信息 |
| data | object/array/null | 业务数据，失败时为 null |

### 1.4 HTTP 状态码

| 状态码 | 含义 |
| --- | --- |
| 200 | 成功 |
| 404 | 资源不存在 |
| 422 | 参数校验失败 |
| 500 | 服务器内部错误 |

## 二、评分查询接口（外部系统接入核心）

> 供外部系统按候选人 ID 查询其面试评分结果。

### 2.1 按候选人查询评分

**请求**

```
GET /api/scores/candidate/{candidate_id}
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| candidate_id | path | string (UUID) | 是 | 候选人 ID，创建面试会话时返回 |

**响应示例（面试已完成，有报告）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "candidate": {
      "id": "6a48769f-af78-4cd1-9781-c3bdaa0cd776",
      "name": "张三",
      "email": "zhangsan@example.com",
      "phone": "13800000000"
    },
    "session_id": "8c412377-1436-4736-a251-8eb4f9573f1e",
    "status": "finished",
    "score": {
      "total_score": 58.1,
      "verdict": "不推荐",
      "summary": "综合评分 58.1 分（满分 100）……",
      "dim_scores": [
        {
          "key": "tech_depth",
          "name": "技术深度",
          "weight": 0.4,
          "score": 5.17,
          "weighted_score": 2.07
        }
      ]
    }
  }
}
```

**字段说明**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| candidate.id | string | 候选人 ID |
| candidate.name | string | 姓名 |
| candidate.email | string/null | 邮箱 |
| candidate.phone | string/null | 电话 |
| session_id | string/null | 最近一场面试会话 ID（无会话时为 null） |
| status | string/null | 会话状态：pending（待面试）/ running（面试中）/ finished（已完成） |
| score.total_score | number/null | 综合分（百分制 0~100），未出报告时为 null |
| score.verdict | string/null | 录用建议：强烈推荐 / 推荐 / 待定 / 不推荐 |
| score.summary | string/null | 总体评价与风险提示 |
| score.dim_scores | array | 各维度得分 |
| dim_scores[].key | string | 维度 key |
| dim_scores[].name | string | 维度名称 |
| dim_scores[].weight | number | 维度权重 |
| dim_scores[].score | number | 该维度各题均分 |
| dim_scores[].weighted_score | number | 加权得分（score × weight） |

**边界情况**

| 情况 | 返回 |
| --- | --- |
| 候选人存在但无任何会话 | `session_id` 和 `score` 均为 null，`status` 为 null |
| 有会话但面试未完成（无报告） | `status` 为 running/pending，`score` 内各字段为 null，`dim_scores` 为空数组 |
| 候选人不存在 | `code: 404`，message「候选人不存在」 |
| candidate_id 格式非法 | `code: 422` |

## 三、面试报告查询接口（含逐题明细）

### 3.1 按会话查询报告 + 逐题评分

```
GET /admin/sessions/{session_id}/report
```

**响应示例**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "session_id": "8c412377-...",
    "status": "finished",
    "report": {
      "dim_scores": [],
      "total_score": 58.1,
      "verdict": "不推荐",
      "summary": "..."
    },
    "evaluations": [
      {
        "question_id": "q1",
        "scores": { "tech_depth": 5.5 },
        "comment": "评分理由（含原话佐证）",
        "follow_up_needed": true,
        "follow_up_question": "追问内容",
        "created_at": "2026-10-10T03:20:00+00:00"
      }
    ]
  }
}
```

> 说明：`evaluations` 为该场面试每一题的评分明细（含追问轮次的评分）。

## 四、管理端接口

### 4.1 岗位管理

**岗位列表**
```
GET /admin/jobs
```

**创建岗位**
```
POST /admin/jobs
Content-Type: application/json

{
  "title": "店员",
  "jd_text": "负责门店日常运营…",
  "requirements": { "skills": ["服务意识", "沟通能力"] }
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| title | string | 是 | 岗位名称 |
| jd_text | string | 否 | JD 描述 |
| requirements | object | 否 | 岗位要求（JSON 对象） |

**删除岗位**
```
DELETE /admin/jobs/{job_id}
```
> 级联删除该岗位下的所有模板、会话、评分、报告、候选人、简历。

### 4.2 面试模板管理

**模板列表**
```
GET /admin/templates
```

**创建模板**
```
POST /admin/templates
Content-Type: application/json

{
  "job_id": "0ddbb62d-...",
  "questions": [
    { "id": "q1", "text": "请介绍你的相关经验" }
  ],
  "rubric": [
    {
      "key": "tech_depth",
      "name": "技术深度",
      "description": "对技术原理的理解程度",
      "weight": 0.4,
      "max_score": 10
    }
  ],
  "duration_limit": 30,
  "max_follow_ups": 2
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| job_id | string (UUID) | 是 | 岗位 ID |
| questions | array | 是 | 预设问题集，每项含 `id`、`text` |
| rubric | array | 是 | 评分维度，每项含 `key`/`name`/`description`/`weight`/`max_score`，权重之和应为 1 |
| duration_limit | int | 否 | 面试时长上限（分钟），默认 30 |
| max_follow_ups | int | 否 | 每题追问上限，默认 2 |

**删除模板**
```
DELETE /admin/templates/{template_id}
```
> 级联删除该模板下的所有会话、评分、报告、候选人、简历。

### 4.3 面试会话管理

**会话列表**
```
GET /admin/sessions?job_id={job_id}&status={status}
```
> `job_id`、`status` 为可选筛选参数。返回含 `candidate_name` 字段。

**创建会话（发起面试）**
```
POST /admin/sessions
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| template_id | string (UUID) | 是 | 模板 ID |
| name | string | 是 | 候选人姓名 |
| email | string | 否 | 邮箱 |
| phone | string | 否 | 电话 |
| file | file | 否 | 简历文件（PDF/DOCX/TXT） |

**响应示例**
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "8c412377-...",
    "token": "9a48add7...",
    "thread_id": "5514df57-...",
    "template_id": "5adcb923-...",
    "candidate_id": "6a48769f-...",
    "status": "pending"
  }
}
```

> ⚠️ **重要**：响应中的 `candidate_id` 就是外部系统查询评分（接口 2.1）所需的参数；`token` 是候选人的面试码（拼在 `/i/{token}` 后即面试链接）。

**删除会话**
```
DELETE /admin/sessions/{session_id}
```
> 级联删除评分、报告、简历、候选人。

## 五、候选人端接口

### 5.1 获取面试上下文（出题）

```
GET /interview/{token}
```

> 候选人须先同意《安全知情协议》（见 5.2），否则仅返回 `consent_required`：不跑图、不返回题目、不消耗 LLM。

**响应示例（已同意）**
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "session_id": "8c412377-...",
    "opening": "张三，你好！欢迎参加本次 AI 面试…",
    "question": "请介绍一下你在高并发后端系统开发中的经验…",
    "question_id": "q1",
    "progress": { "current": 0, "total": 3 },
    "status": "running",
    "consent": { "required": true, "agreed": true, "agreed_at": "2026-10-12T03:54:00+00:00" }
  }
}
```

**响应示例（未同意，前端展示协议页）**
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "session_id": "8c412377-...",
    "opening": "",
    "question": "",
    "question_id": "",
    "progress": { "current": 0, "total": 0 },
    "status": "consent_required",
    "consent": { "required": true, "agreed": false, "agreed_at": null }
  }
}
```

### 5.2 同意《安全知情协议》

```
POST /interview/{token}/consent
```

> 候选人端勾选「我已阅读并同意《安全知情协议》」后调用；幂等，重复调用保留首次同意时间。

**响应示例**
```json
{ "code": 0, "message": "ok", "data": { "required": true, "agreed": true, "agreed_at": "2026-10-12T03:54:00+00:00" } }
```

### 5.3 提交回答

```
POST /interview/{token}/answer
Content-Type: application/json

{ "answer": "我的回答内容…" }
```

**响应示例（三种状态）**

追问：
```json
{ "code": 0, "message": "ok", "data": { "status": "follow_up", "question": "追问内容…", "question_id": "q1", "progress": { "current": 0, "total": 3 }, "message": "" } }
```

下一题：
```json
{ "code": 0, "message": "ok", "data": { "status": "next_question", "question": "下一题…", "question_id": "q2", "progress": { "current": 1, "total": 3 }, "message": "" } }
```

完成：
```json
{ "code": 0, "message": "ok", "data": { "status": "finished", "question": "", "question_id": "", "progress": { "current": 3, "total": 3 }, "message": "面试已完成，感谢参与！" } }
```

| status 值 | 含义 |
| --- | --- |
| follow_up | AI 追问，需继续回答 |
| next_question | 进入下一题 |
| finished | 面试完成 |

> 未同意《安全知情协议》时返回 HTTP 403：`{ "code": 403, "message": "请先阅读并同意《安全知情协议》后再进行面试", "data": null }`。

## 六、外部系统接入建议流程

如果外部系统需要「发起面试 → 获取评分」，推荐流程：

1. **创建/复用岗位**：`POST /admin/jobs`（或直接用已有岗位）
2. **创建/复用模板**：`POST /admin/templates`
3. **发起面试**：`POST /admin/sessions`，拿到 `candidate_id` 和 `token`
4. **候选人面试**：候选人访问 `/i/{token}` 完成面试
5. **获取评分**：`GET /api/scores/candidate/{candidate_id}`，拿到综合分、等级、维度得分

若外部系统**只读评分**（已有面试数据），只需调用接口 2.1 即可。

## 八、注意事项

1. **评分数据落库时机**：报告在候选人完成整场面试后才生成落库；面试进行中查询评分会得到 `score` 为 null。
2. **一个候选人多次面试**：评分接口取该候选人**最近一场**面试的结果。
3. **删除不可恢复**：删除岗位/模板/会话会级联删除关联数据，调用删除接口前请谨慎。
4. **公网域名会变化**：临时域名不稳定，生产接入请使用固定域名 + 鉴权。
